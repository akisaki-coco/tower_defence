# CopilotPlayer - 改善版（v1.1）

## 🔄 変更履歴

### v1.1 - 初期中立兵士数を考慮した戦略改善

#### 問題の修正
1. **中央ハブへの無謀な攻撃を修正**
   - 中央ハブ（要塞4, 7）は30兵士の強力な中立要塞
   - 以前は兵力不足でも攻撃を繰り返していた
   - 攻撃成功判定を厳格化し、無理な攻撃を回避

2. **初期中立兵士数の考慮**
   - 初期配置: `[10, 0, 10, 20, 30, 20, 20, 30, 20, 10, 0, 10]`
   - 0の位置は初期から味方・敵が保持
   - 中立勢力も時間経過で兵士が増加する

#### 主な改善点

##### 1. 攻撃成功判定の厳格化（evaluator.py）
```python
# より保守的な評価
- 最低3兵士必要
- 移動ロス: 2% → 5%
- 敵の生産予測: 1.0倍 → 1.5倍（保守的）
- 成功に必要な残存兵力: >0 → >1.0
- 成功確率の上限: 100% → 95%
```

##### 2. 序盤戦略の改善（strategy.py）

**弱い要塞を優先：**
- **10兵士の要塞**: 最優先（優先度+150、序盤+250）
  - 要塞0, 2, 9, 11
- **20兵士の要塞**: 中優先（優先度+50〜80）
  - 要塞3, 5, 6, 8
- **30兵士の要塞**: 慎重（条件付き）
  - 要塞4, 7（中央ハブ）
  - 25兵士以上 + 90%成功率で攻撃

**成功率の閾値：**
```python
# 初期兵士数に応じた閾値
- 10兵士: 65%以上で攻撃
- 20兵士: 75%以上で攻撃
- 30兵士: 85%以上で攻撃
```

##### 3. 敵攻撃戦略の改善
```python
# より慎重な攻撃
- 最低兵士数: 序盤15、中盤以降12
- 成功率閾値: 終盤75%、それ以外80%
- 中央ハブ: 85%以上の成功率で攻撃
```

##### 4. 高度な戦術の調整
```python
# チョークポイント攻撃
- 中央ハブ: 25兵士 + 80%成功率
- その他: 10兵士 + 80%成功率

# 拡張回廊
- 弱い要塞（10兵以下）のみ対象
```

## 🎯 新しい戦略の流れ

### Phase 1: 序盤（ステップ0-3000）
1. **弱い中立要塞を最優先で制圧**（10兵士）
   - 要塞0, 2, 9, 11
   - これらは初期から隣接または近い
2. **兵力の蓄積**
   - アップグレードで生産力向上
   - 後方要塞から前線へ部隊集結
3. **中程度の要塞への進出**（20兵士）
   - 十分な兵力が揃ってから

### Phase 2: 中盤（ステップ3000-15000）
1. **経済成長**
   - 保持要塞のアップグレード
2. **中央ハブへの挑戦準備**
   - 25兵士以上を蓄積
   - 90%以上の成功率を確保
3. **敵要塞への攻撃**
   - 弱い敵要塞を優先

### Phase 3: 終盤（ステップ15000-50000）
1. **総力戦**
   - 確実に勝てる攻撃のみ実行
2. **決定的な攻撃**
   - 敵の重要拠点を集中攻撃

## 📊 期待される改善効果

### Before（v1.0）
- 中央ハブに無謀な攻撃
- 兵力不足でループ
- 初期拡張が遅い

### After（v1.1）
- 弱い要塞から確実に制圧
- 無理な攻撃を回避
- 効率的な初期拡張
- 中央ハブは準備が整ってから
