# CopilotPlayer - 最強タワーディフェンスAI

## 概要
CopilotPlayerは、複数の高度な戦略とアルゴリズムを組み合わせた、最適化されたタワーディフェンスAIプレイヤーです。

## 主な特徴

### 1. 多次元要塞評価システム
- **戦略的価値**: グラフ中心性（次数中心性、近接中心性）
- **戦術的価値**: 隣接する敵/味方要塞の数、前線からの距離
- **経済的価値**: 生産効率、レベル、種類
- **軍事的価値**: 部隊数、攻撃力、防御力

### 2. 動的戦況分析
- リアルタイムで戦況を多角的に分析
- 領域支配度の計算
- 戦力バランスの評価
- 脅威レベルの算出

### 3. 適応的戦略選択
- **序盤**: 中立要塞の高速制圧、重要拠点の確保
- **中盤**: 経済成長と軍事拡大のバランス、戦線の構築
- **終盤**: 総力戦、決定的な攻撃

### 4. 先読みシミュレーション
- 攻撃成功率の高精度予測
- 敵の行動パターン予測
- 複数手先の戦況シミュレーション

### 5. リスク管理
- 攻撃リスクの評価
- 防御優先度の動的計算
- 資源配分の最適化

## 戦略モジュール

### evaluator.py
要塞と戦況の評価を行うモジュール
- 要塞の多次元評価
- グラフ理論による中心性計算
- 生産効率の計算

### strategy.py
戦略決定エンジン
- 攻撃戦略（中立制圧、敵要塞攻撃）
- 防御戦略（脅威対応、援軍派遣）
- 経済戦略（効率的アップグレード）
- 再配置戦略（部隊の最適配置）

### optimizer.py
行動の最適化
- 優先度付きアクションキュー
- リスク・リターン分析
- 資源配分の最適化

### predictor.py
予測とシミュレーション
- 攻撃成功率の予測
- 部隊到着時間の計算
- 敵の生産予測

## 使用方法

```python
from tcg.game import Game
from tcg.players.CopilotPlayer import CopilotPlayer
from tcg.players.sample_random import RandomPlayer

# CopilotPlayer vs RandomPlayer
Game(CopilotPlayer(), RandomPlayer()).run()
```

## パラメータ調整

`player.py`内の定数を調整することで、AIの行動を微調整できます：

- `EARLY_GAME_THRESHOLD`: 序盤の終了ステップ数
- `MID_GAME_THRESHOLD`: 中盤の終了ステップ数
- 各種重み係数: 評価関数の調整

## アルゴリズムの特徴

1. **O(n²)の効率的なグラフ分析**: 要塞数が少ないため全探索可能
2. **ヒューリスティック探索**: 完全な先読みは計算コストが高いため、評価関数ベース
3. **動的計画法的アプローチ**: 過去の状態を記憶して学習
4. **貪欲アルゴリズム**: 各ターンで最適な行動を選択

## 実装の工夫

- **抜け穴の活用**: 
  - 要塞の生産タイミングを利用した効率的な資源管理
  - グラフトポロジーの非対称性を利用した戦略配置
  - クールダウンの最適化
  
- **数理最適化**:
  - 線形計画法的な資源配分
  - ゲーム理論的な意思決定
  - 確率論的なリスク評価
